How do I create a quicklink?
Enter a unique quicklink name, a target URL, and optional tags, then click Create Quicklink.
Can I update a quicklink?
Yes. Use the console to block or delete existing quicklinks.
How do I know if an action succeeded?
Check the message banner in the UI and review audit events in the console.
